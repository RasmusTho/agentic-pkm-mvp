# 6.0 Agentloop (deterministisk)

## Graf
`retrieve -> draft -> self-check -> final` (max 2 iterationer)

## Promptstruktur
- Instruktioner
- Kontext (citerade utdrag med käll-ID)
- Fråga
- Krav (format, språk, källhänvisning)

## Svarskontrakt
- `Sammanfattning`
- `Källor` (lista: doc_id + ev. tidsstämplar)
