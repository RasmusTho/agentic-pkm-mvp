# Agentminne v1 – Överblick
Syfte: stödja PER-loop (plan–execute–reflect) med episodiskt, semantiskt och proceduralt minne. SoT v4.1 är kognitiv sanning.
Mål: låg latens, idempotens, spårbarhet via trace_id, enkel UPSERT mot AMG/SetDB.
Icke-mål: långsiktig vektor-RAG, cross-user federation, autoskalning.
